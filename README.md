# KeerthiMart

Native C++20 multi-seller e-commerce capstone project.

## Planned modules
- Buyer registration/login
- Seller product management
- Product search/filter
- Shopping cart
- Checkout
- Order history
- Admin panel
- Product reviews and ratings
- AI chatbot

## Technology
C++20, Drogon, CMake, vcpkg, PostgreSQL/SQLite, HTML, CSS, JavaScript.
